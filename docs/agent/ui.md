# Локальный агент — интерфейс

Окно: небольшое Swing-приложение **TimeTracker** с темой **FlatLaf** (`UiTheme`):
светлый фон, бирюзовый акцент, скруглённые кнопки, крупный таймер по центру.

Закрытие (крестик) или сворачивание **не завершает** процесс — приложение уходит в системный трей. Выход только через меню трея → **Exit**.

---

## Первый запуск: Activation

Показывается, если в `settings.json` ещё нет `setupCompleted: true`  
(или файл настроек удалён).

| Элемент | Действие | Условия / ограничения |
|---|---|---|
| Поле **Activation key** | Ввод ключа привязки к веб-аккаунту | Пока ключ **не проверяется на сервере** — достаточно непустой строки |
| **Activate** | Сохраняет ключ, режим не local-only, закрывает диалог | Если поле пустое — предупреждение, диалог не закрывается |
| **Continue locally** | Режим «только локально», ключ не сохраняется | Sync на сервер будет недоступен |

После выбора диалог больше не показывается, пока не сбросить настройки.

Сброс активации:
```powershell
Remove-Item $env:USERPROFILE\.timetracker\settings.json
```

## Вкладка Tracker (главная)

| Элемент | Что делает | Условия / ограничения |
|---|---|---|
| **Work time today** | Сумма **активного** (не IDLE) времени за сегодня | Считается из сохранённых интервалов + текущего открытого (если идёт запись и не IDLE) |
| **Status** | `tracking` / `paused` | Зависит от Start/Pause |
| **Start** | Включает запись времени, при первом нажатии поднимает мониторы ОС | Пока на паузе — интервалы не пишутся |
| **Pause** | Останавливает запись, закрывает текущий интервал | Мониторы могут оставаться в памяти; учёт времени не идёт |
| Список **Applications today** | Приложения и время за сегодня | Только non-IDLE; пусто → текст «No application activity yet» |
| **Send to server** | Заглушка: показывает «not implemented» | **Активна**, только если есть ключ и режим не local-only (`UserSettings.isServerSyncEnabled()`). В local-only — disabled + tooltip почему |

### Когда время растёт
1. Нажат **Start**
2. Статус не IDLE (есть активность мыши/клавиатуры в пределах timeout)
3. Идёт фокус на каком-то окне (имя приложения для списка)

### IDLE
Если нет ввода дольше `idle.timeout.seconds` (по умолчанию 1 минута):
- статус IDLE
- рабочее время в статистику не пишется
- любое движение мыши/клавиша → снова ACTIVE (если трекинг не на паузе)

## Вкладка Statistics

| Элемент | Что делает | Условия / ограничения |
|---|---|---|
| **Period** | Day / Week / Month / Year / All time | Week ≈ последние 7 дней, Month ≈ 30, Year ≈ 365 (скользящее окно, не календарный месяц/год) |
| **Total active time** | Сумма за период | Только non-IDLE интервалы |
| **By day** | Разбивка по датам | Пусто → «No data for this period» |
| **By application** | Разбивка по процессам | Сортировка по убыванию времени |

Данные берутся из `intervals.json` + текущий открытый интервал (если есть).

## Системный трей

| Действие | Результат |
|---|---|
| Закрыть окно / свернуть | Окно скрыто, процесс жив, иконка в трее |
| Двойной клик по иконке / **Open** | Окно снова видно |
| **Exit** | Остановка трекинга и выход из приложения |

Если OS не поддерживает SystemTray — предупреждение в логах, приложение всё равно работает окном.

## Язык UI
Тексты кнопок/подписей — из i18n (`tracker-common`, en/uk).  
Сейчас язык задаётся настройками/конфигом, **переключателя в окне пока нет**.

Логи в консоли всегда на английском и **не** зависят от языка UI.
